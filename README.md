# Ruhr Denim Testshop

Ein Übungs-Onlineshop für Webanalyse. Nichts wird verkauft oder bezahlt.

- `gtm.js` – hier trägst du in **einer Zeile** deine Google-Tag-Manager-ID ein.
- `shop.js` – Shop-Logik. Meldet `view_item_list`, `add_to_cart`, `begin_checkout` und `purchase` an den dataLayer (GA4-Format).
- `index.html`, `kasse.html`, `danke.html` – die drei Seiten.

Unten auf jeder Seite zeigt der **Data-Layer-Monitor** live, was gemeldet wird.
